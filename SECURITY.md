# Security policy

## Supported versions

Only the latest release on `main` gets security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub:
open the [Security tab](https://github.com/medaminben/Bowlingbox/security) and choose
**Report a vulnerability**
([direct link](https://github.com/medaminben/Bowlingbox/security/advisories/new)).

Include what is affected, how to reproduce it, and what an attacker could do with it. You should get
an answer within a week. Once a fix is released, the advisory is published and you are credited
unless you prefer not to be.

Bowlingbox downloads Bullet3, GLM, GoogleTest and possibly wxWidgets at configure time. Problems in
those projects belong with their maintainers. Do report it here if Bowlingbox pins a vulnerable
version.
