# Drop Qt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove every Qt dependency and rebuild BowlingDisplay as a wxWidgets score sheet that keeps the Qt form's look and behaviour.

**Architecture:** `BowlingDisplay::MainWindow` becomes a `wxFrame` laid out in C++ with sizers (no XRC). The window and its five tests live in `bowlingdisplay_core`, linked to `wx::core` and `wx::base`, and the executable is a `WX_ui` app built only when `BUILD_WX_UI=ON`. Qt's option, module, scaffold templates, and docs go away; an old `-DBUILD_QT_UI` cache entry is left as CMake's unused-variable warning.

**Tech Stack:** C++20, CMake ≥ 3.29, wxWidgets 3.2 (system), GoogleTest 1.15.2, ctest, xvfb.

**Spec:** docs/superpowers/specs/2026-10-15-drop-qt-design.md

## Global Constraints

- Branch `refactor/drop-qt`, based on `refactor/apps`. Do not move `refactor/apps`.
- BowlingDisplay stays a separate executable, built with `BUILD_WX_UI=ON` next to BowlingGL. It needs `wx::core` and `wx::base`, not OpenGL.
- The window is laid out in C++ with sizers, like `BowlingFrame`. No XRC (`wxUSE_XRC` is off) and no form designer.
- The window is tested as a real wx window. CI runs the tests under `xvfb-run`.
- Fixed size 1200×200, title `https://github.com/medaminben`.
- Top row: static box "Pins Down" (`pinsGroup`) with buttons `btn_0` … `btn_10` labelled `0` … `10`, then `btn_restart` labelled `⟲`.
- Bottom row: ten untitled boxes `frame1` … `frame10`. Each has `lblRoll1Frame{f}`, `lblRoll2Frame{f}` (frame 10 also `lblRoll3Frame10`) above `lblScoreFrame{f}`. Then box `GameScore` with `lblScore` in a 20 pt bold font. Cells are centred.
- Every widget is created with its name set, so `wxWindow::FindWindowByName(name, window)` finds it.
- `pinsGroup` is a `wxStaticBox` (via `wxStaticBoxSizer`); the buttons are its children, so disabling it disables them.
- `MainWindow(wxWindow* parent = nullptr, std::unique_ptr<IBowlingGame> game = nullptr)`; the game defaults to `ScoreCalculator`.
- Pin button `n` calls `roll(n)`; `btn_restart` calls `restart()` (`reset()` exactly once); both end in `refresh()`.
- `updateGrid()` fills the cells from `Score::frames()` and `notation()`, and `lblScore` from `score()`.
- `updatePinButtons()`: `pinsGroup` is disabled when the game is over; button `n` is shown when the game is over or `n <= pinsLeft()`. After showing or hiding buttons the pins sizer is laid out again.
- A click sends `wxEVT_BUTTON` with the button's id and the button as event object to the button (`ProcessWindowEvent`).
- Hidden means `!IsShown()`, disabled means `!IsEnabled()`.
- `main()` of the test calls `InitGoogleTest` first. With `--gtest_list_tests` it runs gtest without starting wx. Otherwise it calls `wxEntryStart`; on failure it prints `test_bowlingdisplay needs a display; run it under xvfb-run` and returns 1. It calls `wxEntryCleanup` after the tests.
- Each test destroys its window before it ends.
- Test labels: `unit;gui`. `build_gtest_executable` gets an optional `LABELS` argument (default `unit`).
- `applications/bowlingGame/CMakeLists.txt` adds `bowlingGameUI` inside `if(BUILD_WX_UI)`.
- CMake for the core library and executable is the spec's `add_library` / `target_link_libraries` / `create_application` block. Keep `target_include_directories` and `bowlingbox_set_warnings` so `test/` can include the header and the target stays under `-Werror`.
- CI: `apt-get install` adds `xvfb`. Test step: `xvfb-run -a ctest --output-on-failure --label-regex unit`. Configure drops `-DBUILD_QT_UI=OFF`.
- `git grep -i -E '\bqt|QT_'` outside `docs/superpowers/` finds nothing.
- No shim for `BUILD_QT_UI`. An old cache variable only gets CMake's unused-variable warning.
- Out of scope: `libraries/`, BowlingGL, BowlingConsole, the wx scaffold template.
- Builds stay under the repo `build/`. Reuse `build/_deps` with `FETCHCONTENT_SOURCE_DIR_*` and `FETCHCONTENT_FULLY_DISCONNECTED=ON`. Do not pass `-DBUILD_QT_UI` once the option is gone.
- `licenses/` is untracked at this HEAD. Delete the untracked `licenses/Qt-LGPL-3.0.txt` and remove the Qt 6 row from the untracked `licenses/README.md`. Do not `git add` the rest of `licenses/`.

#include <Bowlingbox/Score/Score.h>
#include <gtest/gtest.h>

namespace {
class CountingGame final : public Bowlingbox::Score::IBowlingGame {
public:
    explicit CountingGame(int& resets) : _resets(resets) {}
    bool roll(int pins) override { return _inner.roll(pins); }
    void reset() override {
        ++_resets;
        _inner.reset();
    }
    std::vector<int> rolls() const override { return _inner.rolls(); }
    std::vector<int> scores() const override { return _inner.scores(); }
    int score() const override { return _inner.score(); }
    int frameScore(int frameIndex) const override { return _inner.frameScore(frameIndex); }
    int pinsLeft() const override { return _inner.pinsLeft(); }
    bool isOver() const override { return _inner.isOver(); }

private:
    Bowlingbox::Score::ScoreCalculator _inner;
    int& _resets;
};

class WindowGuard {
public:
    explicit WindowGuard(std::unique_ptr<Bowlingbox::Score::IBowlingGame> game = nullptr)
        : _window(new BowlingDisplay::MainWindow(nullptr, std::move(game))) {
        _window->Show();
    }
    ~WindowGuard() { _window->Destroy(); }
    BowlingDisplay::MainWindow& get() { return *_window; }

private:
    BowlingDisplay::MainWindow* _window;
};

wxString text(wxWindow& w, const char* name) {
    auto* label = dynamic_cast<wxStaticText*>(wxWindow::FindWindowByName(name, &w));
    return label->GetLabel();
}
wxButton* pinButton(wxWindow& w, int pins) {
    return dynamic_cast<wxButton*>(
        wxWindow::FindWindowByName(wxString::Format("btn_%d", pins), &w));
}
void click(wxButton* button) {
    wxCommandEvent event(wxEVT_BUTTON, button->GetId());
    event.SetEventObject(button);
    button->ProcessWindowEvent(event);
}
void roll(wxWindow& w, std::initializer_list<int> pins) {
    for (int p : pins)
        click(pinButton(w, p));
}
}  // namespace

/**
  @file ScoreSheetFrame.cpp
  @details the wx score sheet window: rolls go to the game, the sheet is redrawn from it
*/
#include "ScoreSheetFrame.h"
#include <Bowlingbox/Score/Frames.h>
#include <Bowlingbox/Score/Notation.h>
#include <Bowlingbox/Score/Score.h>
#include <wx/button.h>
#include <wx/sizer.h>
#include <wx/statbox.h>
#include <wx/stattext.h>

namespace BowlingDisplay {
namespace {
wxStaticText* makeCell(wxWindow* parent, const wxString& name, const wxFont& font) {
    auto* label = new wxStaticText(parent, wxID_ANY, wxEmptyString, wxDefaultPosition,
                                   wxSize(30, 30), wxALIGN_CENTRE_HORIZONTAL);
    label->SetName(name);
    label->SetFont(font);
    return label;
}
}  // namespace

MainWindow::MainWindow(wxWindow* parent, std::unique_ptr<Bowlingbox::Score::IBowlingGame> game)
    : wxFrame(parent, wxID_ANY, "https://github.com/medaminben", wxDefaultPosition, wxSize(1200, 200)),
      _game(game ? std::move(game) : std::make_unique<Bowlingbox::Score::ScoreCalculator>()) {
    SetMinSize(wxSize(1200, 200));
    SetMaxSize(wxSize(1200, 200));

    const wxFont rollFont(wxFontInfo(12).Bold());
    const wxFont frameFont(wxFontInfo(14));
    auto* root = new wxBoxSizer(wxVERTICAL);

    auto* pinsBox = new wxStaticBox(this, wxID_ANY, "Pins Down");
    pinsBox->SetName("pinsGroup");
    _pinsSizer = new wxStaticBoxSizer(pinsBox, wxHORIZONTAL);
    for (int pins = 0; pins <= Bowlingbox::Score::kPins; ++pins) {
        auto* button = new wxButton(pinsBox, wxID_ANY, wxString::Format("%d", pins),
                                    wxDefaultPosition, wxSize(30, 30));
        button->SetName(wxString::Format("btn_%d", pins));
        button->SetMinSize(wxSize(30, 30));
        button->SetMaxSize(wxSize(30, 30));
        button->Bind(wxEVT_BUTTON, [this, pins](wxCommandEvent&) { roll(pins); });
        _pinButtons.push_back(button);
        _pinsSizer->Add(button, 0, wxALL, 2);
    }

    auto* restart = new wxButton(this, wxID_ANY, wxString::FromUTF8("⟲"), wxDefaultPosition,
                                 wxSize(100, 73));
    restart->SetName("btn_restart");
    restart->SetFont(wxFontInfo(28));
    restart->Bind(wxEVT_BUTTON, [this](wxCommandEvent&) { this->restart(); });

    auto* top = new wxBoxSizer(wxHORIZONTAL);
    top->Add(_pinsSizer, 0, wxEXPAND | wxALL, 4);
    top->AddStretchSpacer(1);
    top->Add(restart, 0, wxALIGN_CENTER_VERTICAL | wxALL, 4);
    root->Add(top, 0, wxEXPAND);

    auto* frames = new wxBoxSizer(wxHORIZONTAL);
    for (int frame = 1; frame <= Bowlingbox::Score::kFrames; ++frame) {
        auto* box = new wxStaticBox(this, wxID_ANY, wxEmptyString);
        box->SetName(wxString::Format("frame%d", frame));
        auto* boxSizer = new wxStaticBoxSizer(box, wxVERTICAL);
        auto* rolls = new wxBoxSizer(wxHORIZONTAL);
        const int rollCount = frame == Bowlingbox::Score::kFrames ? 3 : 2;
        for (int r = 1; r <= rollCount; ++r) {
            auto* label = makeCell(box, wxString::Format("lblRoll%dFrame%d", r, frame), rollFont);
            rolls->Add(label, 1, wxALIGN_CENTER | wxALL, 1);
            _rollLabels.push_back(label);
        }
        boxSizer->Add(rolls, 0, wxEXPAND);
        auto* score = makeCell(box, wxString::Format("lblScoreFrame%d", frame), frameFont);
        boxSizer->Add(score, 1, wxALIGN_CENTER | wxEXPAND);
        _scoreLabels.push_back(score);
        frames->Add(boxSizer, 1, wxEXPAND | wxLEFT | wxRIGHT, 2);
    }

    auto* gameBox = new wxStaticBox(this, wxID_ANY, wxEmptyString);
    gameBox->SetName("GameScore");
    auto* gameSizer = new wxStaticBoxSizer(gameBox, wxVERTICAL);
    _total = makeCell(gameBox, "lblScore", wxFontInfo(20).Bold());
    gameSizer->Add(_total, 1, wxALIGN_CENTER | wxEXPAND);

    auto* bottom = new wxBoxSizer(wxHORIZONTAL);
    bottom->Add(frames, 1, wxEXPAND);
    bottom->Add(gameSizer, 0, wxEXPAND | wxLEFT | wxRIGHT, 4);
    root->Add(bottom, 1, wxEXPAND);

    SetSizer(root);
    refresh();
}

void MainWindow::roll(int pins) {
    _game->roll(pins);
    refresh();
}

void MainWindow::restart() {
    _game->reset();
    refresh();
}

void MainWindow::refresh() {
    updateGrid();
    updatePinButtons();
}

void MainWindow::updateGrid() {
    for (const auto& frame : Bowlingbox::Score::frames(*_game)) {
        for (int r = 0; r < frame.rollCount; ++r) {
            _rollLabels.at(static_cast<std::size_t>(2 * frame.index + r))
                ->SetLabel(wxString::FromUTF8(
                    Bowlingbox::Score::notation(frame.rolls[static_cast<std::size_t>(r)])));
        }
        _scoreLabels.at(static_cast<std::size_t>(frame.index))
            ->SetLabel(wxString::FromUTF8(Bowlingbox::Score::notation(frame.score, true)));
    }
    _total->SetLabel(wxString::Format("%d", _game->score()));
}

void MainWindow::updatePinButtons() {
    const bool over = _game->isOver();
    auto* pinsGroup = wxWindow::FindWindowByName("pinsGroup", this);
    pinsGroup->Enable(!over);
    const int left = _game->pinsLeft();
    for (int pins = 0; pins <= Bowlingbox::Score::kPins; ++pins)
        _pinButtons.at(static_cast<std::size_t>(pins))->Show(over || pins <= left);
    _pinsSizer->Layout();
}
}  // namespace BowlingDisplay
